# Completion protocol — fixed before additional model evaluation

This extends the accepted strict chronological KuaiRec run. It does not alter the previous tree-model results, initial subset or train/val/test assignments. Live paid LLM APIs, GitHub upload and remote CI are excluded at the owner's request.

1. EmbeddingMLP, DeepFM and DIN use the existing temporal-prefix candidate training table and validation table. Injected rows are removed before sampling. Each uses up to 700,000 train and 500,000 validation rows, seed 42, 32-dimensional embeddings, 50 recent positive history items, batches of 1,024 and learning rate .001. Maximum 10 epochs, patience 2 on validation AUC. A fixed log1p transform bounds dense feature scales, and gradient clipping uses norm 5.0. These choices are fixed before new model test evaluation. Report actual completed epochs and selected checkpoint; early stopping is completion of the declared procedure, not a claim that ten epochs ran.
2. BPR, TwoTower, LightGCN and SASRec repeat the existing 32-dimensional configuration for ten epochs on the same strict training split. Test comparisons are descriptive; there is no parameter search or assumption that more epochs must improve quality.
3. Four repaired negative-sampling strategies train fixed 120-tree LambdaRank models. Exposures and popularity are available only from the temporal prefix; no future-label exclusions. Random negatives are random within the live retrieval pool. Specific hard-pool labels follow the existing exposure/popularity/source taxonomy, not a claim of globally hardest negatives. Empty pools cause explicit failure rather than substituting another strategy. Sampling diagnostics keep candidate-recall denominators from all original target positives.
4. Semantic verification adds official static captions to a separate item view, leaving the base features unchanged. Use the pinned revision of multilingual MiniLM and normalized 384-dimensional embeddings with FAISS exact inner-product search. Require the semantic backend, verify numeric agreement with a direct dot product, and verify saved/loaded recommendations. Captions are treated as transductive static metadata; their historical publication-time availability is unknown.
5. Business reranking compares none/diversity/diversity_tail on the same GBDT Top50 input head of 100 items. Membership must be preserved. Report relevance and Top10 category coverage/tail measures, without selecting parameters using test outcomes.
6. Build and test Docker only if a usable engine exists. The current host has no Docker executable/socket and rejects rootless user namespace setup. Record blocked status with evidence rather than reporting an unexecuted build as passed.

`configs/kuairec_completion.yaml` is the frozen specification. `scripts/run_completion.py` orchestrates the stages, records commands and supports resuming completed checkpoints. Model files, features and pretrained weights stay ignored; small logs, configurations, hashes and metric tables are retained. Externally downloaded semantic packages run in a separate environment so the original pinned core remains reproducible.
