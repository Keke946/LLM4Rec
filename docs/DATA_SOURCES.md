# Data source and use

The primary input is the official [KuaiRec repository](https://github.com/chongminggao/KuaiRec), whose download instructions point to [Zenodo record 18164998](https://zenodo.org/records/18164998). The downloaded archive contains the `KuaiRec 2.0` directory. It is 431,964,858 bytes, with published MD5 `261550d472c48eff4990fb13c0e5bcf7`. Exact SHA-256 hashes and acquisition metadata are in `reports/reproduction/data_source.json`.

The official big matrix has 12,530,806 interactions, 7,176 users and 10,728 videos. This project uses the 1,000 most active users, then samples 300,000 rows uniformly without replacement with seed 42. The resulting catalog has 7,483 videos. This is a selected, exposure-biased subset of the big matrix, not the fully observed small-matrix benchmark or a representative production sample.

Fields used: `user_id`, `video_id`, `timestamp` (Unix seconds), and `watch_ratio` (play duration / video duration). `watch_ratio >= 1.0` defines a binary positive. This is a watch-completion proxy, not an observed like or CTR. Videos may loop, so ratios can exceed one. `item_categories.csv` supplies encrypted category/tag lists. This reproduction does not use captions, user demographics, social links, or daily aggregate features. Titles such as `video_123` are placeholders, not video descriptions. Authors and durations are absent from this adapter path and have no meaningful predictive variation.

The archive's LICENSE and the upstream repository specify CC BY-SA 4.0, whereas the Zenodo API metadata reports `cc-by-4.0`. Preserve this discrepancy in the provenance record; use the archive's attribution/share-alike terms conservatively. Raw/processed data and model artifacts are not bundled with the code. Cite Gao et al., *KuaiRec: A Fully-Observed Dataset and Insights for Evaluating Recommender Systems*, CIKM 2022, DOI [10.1145/3511808.3557220](https://doi.org/10.1145/3511808.3557220).

`examples/sample_data/movielens` is an authored, MovieLens-compatible fixture with six invented movie titles. It is not the official MovieLens dataset. The fixture has four test positives so smoke evaluation is nonempty. `examples/sample_data/kuairec` is also a tiny fixture. Neither supplies the real-data metrics in the reproduction report. Missing raw input fails by default; `--allow_sample_fallback` is an explicit demo-only opt-in.
