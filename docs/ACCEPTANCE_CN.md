## 主要结果

严格时间协议，928 个有有效正反馈的测试用户：

| 实验 | Recall@10 | NDCG@10 | MRR@10 |
|---|---:|---:|---:|
| Retrieval Only | 0.006745 | 0.005966 | 0.010812 |
| GBDT Full | 0.004093 | 0.005172 | 0.015532 |
| GBDT Top50 | 0.010793 | 0.010182 | 0.021441 |
| GBDT Top100 | 0.008848 | 0.010896 | 0.030040 |
| LambdaRank Top50 | 0.009253 | 0.010768 | 0.026188 |

GBDT Top50 对比同一候选池，Recall@10 / NDCG@10 / MRR@10 分别相对提升约 60.0% / 70.7% / 98.3%。这是单种子离线描述性结果，不代表线上收益或显著性结论。Top50/100 的 Recall@100 均保持 0.094395。

历史协议的 Retrieval Only 三项 Top10 指标复现到原报告的六位小数；修复后的 GBDT Top50 为 0.026833 / 0.030035 / 0.080106。历史和严格协议不能混为一组结果。

## 重要修复

1. 修复 GBDT 配置及脚本默认值使用 Test 作为验证集的风险，训练入口强制 train/val。
2. 修复候选池大小包含注入标签数量的隐式泄漏。
3. 禁止用未来 val/test 正反馈筛选训练负例；曝光信息仅允许使用训练前缀。
4. 增加全局时间切分，明确原 per-user 协议的跨用户未来行为风险。
5. 修复空候选诊断、Content 保存/加载画像丢失、负采样重试后误采正例及训练/推理历史长度不一致。
6. 改成分批候选写盘和向量化树模型特征，减少复现内存。
7. 依赖固定、可安装打包、测试扩充、原始证据留存、报告追踪、模块状态标注和一键复现脚本。
